# PINN چهار ذره با فقط دو موقعیت اولیهٔ متغیر

این نسخه ادامهٔ فایل Python ارسالی شماست. هر **چهار ذره** و شش پیوند فنر–میراگر میان آن‌ها باقی مانده‌اند. فقط مکان اولیهٔ ذره‌های قطری **۱ و ۳** پارامتری است:

```text
theta = [x10, y10, x30, y30]
ورودی شبکهٔ مسیر: [t, theta]                 → پنج عدد
ورودی شبکهٔ سیال: [x, y, t, theta]           → هفت عدد
خروجی مسیر: مکان هر چهار ذره                → هشت مؤلفه
خروجی سیال: [u, v, p, sigma_xx, sigma_xy, sigma_yy]
```

زمان و مختصات محل ارزیابی همچنان ورودی‌اند؛ **پارامترهای متغیر مسئله فقط همان چهار مختصات اولیه‌اند**. `Re`، `St`، بارگذاری ذرات، هندسه، شعاع و خواص پیوندها در `Config` ثابت‌اند و به شبکه ورودی داده نمی‌شوند. تغییر این ثابت‌ها عموماً به آموزش مجدد نیاز دارد.

مکان اولیهٔ ذرهٔ ۲ برابر `(0.19, 0.14)` و ذرهٔ ۴ برابر `(0.13, 0.26)` است. ثابت‌بودن به **مکان اولیه** اشاره دارد؛ هر چهار ذره در ادامه حرکت می‌کنند. تغییر دو گوشهٔ مقابل می‌تواند کشیدگی و چرخش مجموعه را تحریک کند، ولی وقوع برخورد یا مقدار چرخش از قبل تحمیل نمی‌شود.

## آیا منطق مدل درست است؟

کد ارسالی از نظر ساختار یک مدل بی‌بعد قابل استفاده است: مشتق زمانی مسیر سرعت و شتاب را تعیین می‌کند، نیروهای داخلی مرکزی و برابر و مخالف‌اند، و فقط واکنش درگ به سیال بازگردانده می‌شود. آزمون‌های مشتق‌ها و مکانیک آن نیز اجرا شدند. این نتیجه به‌تنهایی درستی یک جواب آموزش‌دیده یا انطباق آن با آزمایش را ثابت نمی‌کند.

README ارسالی مدل **دو parcel بدون پیوند، جریان اولیهٔ ساکن و هشت پارامتر متغیر** را توصیف می‌کند؛ فایل Python ارسالی مدل **چهار ذرهٔ پیونددار، جریان اولیهٔ برقرار و چهار پارامتر مکانی** است. نسخهٔ حاضر مدل دوم را مبنا قرار می‌دهد. ترکیب شرایط اولیهٔ این دو مدل در یک مسئله سازگار نیست.

انتخاب‌ها و اصلاحات این نسخه:

1. **طول تعادلی پیوندها پیش‌فرض ثابت است.** از هندسهٔ اسمی `q0` محاسبه می‌شود. بنابراین تغییر ورودی، تغییر شکل اولیهٔ همان مجموعه است و می‌تواند نیروی فنری اولیه ایجاد کند. گزینهٔ `rest_lengths="case"` همچنان موجود است، اما با آن هندسهٔ تعادلی پیوندها نیز برای هر حالت تغییر می‌کند؛ این خانوادهٔ دیگری از مسائل است.
2. **سیال در آغاز جریان پایای آموزش‌دیده دارد و ذرات ساکن‌اند.** سرعت اولیهٔ ذرات و مکان اولیه دقیقاً در فرم خروجی شبکه اعمال می‌شوند. نمونه‌های دقیق `t=0` نیز در معادلهٔ ذره گذاشته شده‌اند تا شتاب ناشی از درگ و پیش‌کرنش درست آموزش داده شود.
3. **سیال گذرا همان چهار ورودی مکانی را می‌گیرد.** چون بازخورد ذرات به سیال فعال است، حذف این ورودی‌ها از شبکهٔ سیال به یک میدان واحد برای چند منبع نیروی متفاوت منجر می‌شود. فقط شبکهٔ سیال پایای بدون ذره مستقل از این ورودی‌هاست.
4. **واکنش درگ در دامنهٔ واقعی نرمال می‌شود.** انتگرال کرنل گاوسی روی کانالِ دارای تنگی یک است؛ در نتیجه نیروی بازگشتی نزدیک دیواره از دامنه گم نمی‌شود. توازن نیروی کل با انتگرال‌گیری مستقل آزموده شده است. درگ از سرعت سیال در مرکز ذره نمونه‌برداری می‌شود؛ این تقریب با پخش گاوسی منبع، روش کاملاً مزدوج برای تضمین توازن انرژی سیال–ذره نیست.
5. **تماس دیواره از فاصله تا صفحه‌ها و دایره‌های واقعی محاسبه می‌شود.** تقریب شیب دیواره در شانهٔ نیم‌دایره لازم نیست. تماس یک‌طرفه و نرم است و مقدار اندکی هم‌پوشانی را مجاز می‌کند. نیروها به‌صورت مصنوعی اشباع نمی‌شوند.
6. **هر دو صورت mixed و primitive ناویر–استوکس آموزش و بررسی می‌شوند.** خطای کوچک رابطهٔ تنش به‌تنهایی تضمین نمی‌کند مشتق خطای تنش و معادلهٔ اصلی نیز کوچک باشد. خود کد Python ارسالی شما این بررسی را داشت؛ این ویژگی حفظ شده است.
7. **اعتبارسنجی برای هر ورودی جدا انجام می‌شود.** علاوه بر باقیمانده‌ها و مرزها، مسیر با حلگر مستقل `Radau` در **همان سیال یادگرفته‌شده** مقایسه می‌شود. تعداد و زمان شروع تماس هم بررسی می‌شود. این مقایسه جای حل مستقل CFD یا آزمایش را نمی‌گیرد.

## فرض‌ها و تنظیمات ثابت

| کمیت | مقدار پیش‌فرض |
| --- | --- |
| طول و ارتفاع کانال | `L=1`, `H=0.4` |
| مرکز و شعاع نیم‌دایرهٔ تنگی | `xc=0.4`, `R=0.1` |
| ارتفاع گلوگاه | `H-2R=0.2` |
| `Re`, `St` | `50`, `0.05` |
| سرعت بیشینهٔ ورودی | `U=1` |
| زمان نهایی | `T=0.7` |
| بارگذاری جرمی متوسط مدل | `beta=5e-5` |
| شعاع برخورد مؤثر | `rp=0.015` |
| پهنای منبع گاوسی | `eps=0.025` |
| `x10` | `[0.11, 0.15]` |
| `y10` | `[0.115, 0.165]` |
| `x30` | `[0.17, 0.21]` |
| `y30` | `[0.235, 0.285]` |

بازه‌ها عمداً محدودند تا شروع آموزش با تغییر شکل‌های بسیار شدید دشوار نشود. نمونه‌ها از نظر فاصلهٔ اولیه از دیواره، دو سر کانال و ذرات دیگر کنترل می‌شوند. اعتبارسنجی گوشه‌های مجاز دامنه و چند حالت تصادفیِ جدا از نمونه‌های آموزش را شامل می‌شود. تعداد حالت‌ها قابل افزایش است.

مقادیر مکان و زمان بی‌بعدند، ویسکوزیتهٔ بی‌بعد در معادله `1/Re` است، و مقیاس مرجع پیش‌فرض طول و سرعت هر دو یک است. وقتی `L` یا `U` را تغییر می‌دهید، تعبیر `Re` را نسبت به مقیاس مرجع ثابت حفظ کنید؛ عدد رینولدز مبتنی بر طول و سرعت جدید به‌طور خودکار بازتعریف نمی‌شود.

جریان دوبعدی، تراکم‌ناپذیر و نیوتنی است. ذرات جرم برابر دارند، سرعت اولیه‌شان صفر است و شش پیوند مرکزیِ فنر–میراگر بدون جرم دارند. پیوندها با دیواره تماس مستقل ندارند. این مدل زنجیره یا پوستهٔ جامد نفوذناپذیر نیست. درگ خطی از نوع Stokes است؛ گرانش، Brownian، lubrication، اصطکاک مماسی، lift، added mass و انحلال لحاظ نشده‌اند.

`bond_kn` و `bond_cn` ضرایب تقسیم‌شده بر جرم کاهش‌یافته هستند؛ سهم شتاب هر ذرهٔ هم‌جرم از یک پیوند نصف عبارت نسبی است. تماس ذره–ذره همین قرارداد را دارد؛ ضریب تماس دیواره مستقیماً ضریب شتاب یک ذره است. این قرارداد در NumPy و PyTorch یکسان است.

برای `A=L*H-pi*R**2`، جرم بی‌بعد هر ذره در بازخورد سیال `m=beta*A/4` تعریف می‌شود. `rp` شعاع برخورد **مؤثر مدل** است و به‌تنهایی شعاع فیزیکی ذرهٔ دارویی نیست. برای استفادهٔ کمی باید شعاع واقعی، چگالی، جرم، `St`، `beta` و ضرایب تماس را به‌طور سازگار از مقیاس‌های فیزیکی تعیین کنید. کاهش تعداد ورودی‌ها این کالیبراسیون را انجام نمی‌دهد.

## معادله‌ها و شرایط مرزی

```text
div(u) = 0
u_t + (u · grad)u = div(sigma) + S
sigma = -p I + (grad(u) + grad(u)^T)/Re

q_i' = v_i
v_i' = (u(q_i,t,theta)-v_i)/St + a_bond,i + a_pair,i + a_wall,i
S(x,t,theta) = -sum_i m_i a_drag,i W_i(x,q_i)
integral_domain W_i dA = 1
```

فقط واکنش درگ وارد منبع سیال می‌شود. واکنش تماس داخلی بین ذرات خنثی می‌شود و واکنش تماس دیواره متعلق به جامدِ دیواره است.

ورودی سرعت سهموی ثابت و بدون ramp دارد؛ این شرط با جریان اولیهٔ پایا سازگار است. سرعت دیواره صفر است. خروجی از نوع جریان توسعه‌یافته با `v=0` و **تنش نرمال صفر**، یعنی `-p+2*u_x/Re=0` است؛ شرط فشار صفر و تنش برشی صفر جداگانه تحمیل نشده‌اند. شار هر مقطع برابر `2*U*H/3` است.

فرم مسیر `q=q0(theta)+h(t)*b(t,theta)` است و

```text
h(t)=t+St*(exp(-t/St)-1)
h(0)=0, h'(0)=0
```

بنابراین مکان و سرعت اولیه دقیق‌اند، ولی شتاب باید از معادله یاد گرفته شود. میدان گذرا برابر میدان پایا به‌اضافهٔ یک تصحیح وابسته به چهار ورودی است؛ تصحیح **سرعت** در `t=0` صفر می‌شود. فشار اولیه از قید تراکم‌ناپذیری و منبع نیرو تعیین می‌شود و به صفر مقید نیست.

این نسخه عبور و ادامهٔ فیزیک ذرات بیرون از دو سر کانال را اعتبارسنجی نمی‌کند. خروج مرکز هر ذره از کانال، آزمون عددی را رد می‌کند. اگر زمان نهایی یا سرعت را زیاد کردید، این محدودیت را بررسی کنید.

## نصب و اجرای آزمون‌ها

Python 3.12 و نصب CPU زیر در این محیط استفاده شده‌اند:

```bash
cd /workspace/cloud_particle
python3 -m venv /workspace/.venv
/workspace/.venv/bin/python -m pip install -r requirements.txt
export MPLCONFIGDIR=/workspace/.cache/matplotlib
export XDG_CACHE_HOME=/workspace/.cache
/workspace/.venv/bin/python stenosis_pinn.py --self-test
/workspace/.venv/bin/python stenosis_pinn.py --quick-test --no-gif --outdir results_smoke
```

برای نصب روی کامپیوتر خودتان مسیرها را متناسب تغییر دهید. `requirements.txt` نسخهٔ CPU را مشخص می‌کند. برای GPU نسخهٔ سازگار PyTorch را طبق دستور رسمی PyTorch نصب کنید؛ سپس `--device cuda` را به کار ببرید. دیگر وابستگی‌ها همان‌اند.

`--self-test` مشتق‌ها در مقابل autograd، باقیماندهٔ primitive مستقل، توازن نیرو و گشتاور داخلی، اتلاف انرژی پیوندها، تماس و حل مستقل آن، شرایط اولیه و مرزی، نمونه‌برداری و توازن انتگرالی منبع را می‌آزماید.

`--quick-test` فقط مسیر اجرای آموزش، ذخیره، حل مرجع و تولید خروجی را آزمایش می‌کند. بودجهٔ آن بسیار کوتاه است. **عبور اجرای این فرمان به معنای همگرایی فیزیکی نیست**؛ مدل و گزارش آن با `smoke_test=true` و `passed=false` علامت‌گذاری می‌شوند. تصاویر چنین مدل‌هایی نیز عنوان `UNCONVERGED - DIAGNOSTIC ONLY` دارند.

## آموزش و ارزیابی

```bash
# آموزش کامل: جریان پایا، پیش‌آموزش مسیر، سپس حل کوپل‌شده
/workspace/.venv/bin/python stenosis_pinn.py --outdir results_train --no-gif

# ادامه از وزن‌های ذخیره‌شده؛ پوشهٔ خروجی جدید انتخاب کنید
/workspace/.venv/bin/python stenosis_pinn.py --resume results_train/model.pt --outdir results_resume --no-gif

# ارزیابی یک ورودی: به ترتیب x10, y10, x30, y30
/workspace/.venv/bin/python stenosis_pinn.py --evaluate results_train/model.pt \
  --initial 0.14 0.13 0.18 0.27 --outdir results_single --no-gif

# چند ورودی نمونه
/workspace/.venv/bin/python stenosis_pinn.py --evaluate results_train/model.pt \
  --cases cases_example.json --outdir results_cases --no-gif
```

بدون `--no-gif` انیمیشن هم ساخته می‌شود. پوشهٔ خروجی باید خالی یا جدید باشد تا نتایج قبلی بازنویسی نشوند. checkpointهای نسخه‌های قبلی پارامتری برای resume مستقیم پذیرفته نمی‌شوند. `--carrier-from` فقط انتقال شبکهٔ سیال پایای سازگار از قالب‌های مشخص‌شده در کد را انجام می‌دهد و دوباره اعتبارسنجی می‌کند؛ نیازمند checkpointی است که اینجا ارسال نشده است.

پیش‌فرض‌ها حدود ۶۰۰۰ گام Adam برای پایا و ۵۰۰۰ گام برای کوپل‌شده، به‌علاوهٔ L-BFGS و اصلاح نمونه‌برداری دارند. این‌ها بودجهٔ آغازین هستند و همگرایی را تضمین نمی‌کنند. تماس سخت و مشتق‌های مرتبهٔ دوم روی CPU می‌توانند زمان‌بر باشند. برای تغییر بودجه و دیگر ثابت‌ها یک JSON از فیلدهای `Config` بسازید و `--config settings.json` بدهید؛ لازم نیست آن‌ها را ورودی شبکه کنید.

آموزش کاملِ گزارش‌شده در این تحویل اجرا نشده است. گزارش آزمون‌های واقعاً اجراشده در `VALIDATION_FA.md` قرار دارد. این تحویل وزن آموزش‌دیدهٔ معتبر یا نمودار پیش‌بینی فیزیکی نهایی را ادعا نمی‌کند.

برای استفادهٔ Python پس از یک آموزش که آزمون عددی را گذرانده است:

```python
import numpy as np
from stenosis_pinn import predict_trajectory

result = predict_trajectory(
    "results_train/model.pt",
    times=np.linspace(0, 0.7, 101),
    initial=[0.14, 0.13, 0.18, 0.27],
)
# result['position'].shape == (101, 4, 2)
# result['velocity'] و result['acceleration'] همین شکل را دارند.
```

ورودی جدید باید در دامنهٔ آموزش باشد و بهتر است با `--evaluate --initial` جداگانه بررسی شود. `predict_trajectory` به‌طور پیش‌فرض checkpoint آزمون کوتاه یا آموزشِ تأییدنشده را رد می‌کند. `allow_diagnostic=True` فقط برای اشکال‌زدایی موجود است.

## خواندن گزارش خروجی

هر حالت پوشهٔ `case_...` با مسیر CSV، میدان NPZ، نمودار PNG/PDF، تماس‌ها و گزارش JSON دارد. `model.pt` وزن‌ها و تنظیمات را نگه می‌دارد. گزارش فقط وقتی موفق است که بررسی جریان پایا، PDE گذرا، شار، مرزها، معادله و هم‌پوشانی ذرات و مقایسه با Radau همگی موفق باشند.

آستانه‌های کنونی: RMS بی‌بعد mixed و ODE کمتر از `0.01`، primitive کمتر از `0.05`، خطای شار و سرعت دیواره کمتر از یک درصد مقیاس مربوط، خطای موقعیت Radau کمتر از `0.01*H` و سرعت کمتر از `0.03*U`. خطای شروع هر تماس حداکثر یک درصد بازهٔ زمان یا دو نمونهٔ زمانیِ تشخیص است. این آستانه‌ها معیارهای غربال عددی‌اند و کران ریاضی خطا نیستند.

گزارش finite held-out cases فقط دربارهٔ حالت‌های بررسی‌شده است. برای ادعای صحت کل دامنهٔ چهارپارامتری، آزمون‌های بیشتر و برای اعتبار فیزیکی، مرجع CFD یا دادهٔ تجربی مستقل لازم است.
